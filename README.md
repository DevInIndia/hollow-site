# hollow-site

> Live Website & Documentation: **[https://hollow-site.vercel.app/](https://hollow-site.vercel.app/)**

Static documentation and product marketing website for **[hollow](https://github.com/DevInIndia/hollow)** — a zero-dependency recursive DNS resolver, filtering ad-block server, and protocol toolkit written entirely in pure Go.

Built with Next.js (App Router), React 19, TypeScript, Tailwind CSS v4, and Motion.
